# مقارنة مزودات OTP للهاتف — 2026-11-03

## النطاق
هذه المقارنة تصميمية فقط. لم يُشترَ أي مزود، ولم يُفعّل إرسال حقيقي، ولم تُستخدم قاعدة إنتاجية أو بيانات عملاء. القرار النهائي يحتاج موافقة صريحة وعرض سعر رسمي.

## المتطلبات
- توصيل OTP إلى أرقام اليمن (+967) بثبات، مع بديل عند فشل الشبكة المحلية.
- API واضح للتحقق والإرسال، ومفاتيح قابلة للتدوير، وحدود معدل، وسجل تسليم.
- دعم رمز قصير العمر (5–10 دقائق)، ومنع إعادة الإرسال المفرط.
- عقد بيانات وخصوصية مقبول، وعدم تسريب أرقام أو رموز إلى سجلات التطبيق.
- بيئة اختبار/Sandbox قبل الإنتاج، وتكلفة قابلة للقياس لكل رسالة ناجحة.
- إمكانية استبدال المزود دون تغيير منطق الهوية (`OtpDeliveryAdapter`).

## المزودون المرشحون
| المزود | قناة الإرسال | تغطية اليمن | Sandbox | ملاحظات القرار |
|---|---|---|---|---|
| مجمّع محلي معتمد (Yemen Mobile / Sabafon / You) | SMS محلي | الأعلى نظريًا | غير موحد | يحتاج تعاقدًا محليًا وربطًا مباشرًا؛ الأفضل كقناة أساسية بعد تجربة تسليم فعلية. |
| Twilio | SMS / WhatsApp | دولية، قد تتأثر ببوابات محلية | نعم | API ناضج وحدود معدل واضحة، لكن التسعير والتسليم لأرقام +967 يحتاجان تحققًا فعليًا. |
| Vonage | SMS / WhatsApp | دولية | نعم | بديل تعاقدي، نفس الحاجة لاختبار تسليم اليمن. |
| Meta WhatsApp Business | WhatsApp OTP | يعتمد على انتشار WhatsApp | نعم | يتطلب توثيق نشاط تجاري وقالب رسالة معتمد؛ جيد كقناة ثانوية لا أساسية. |
| مزود بريد إلكتروني | Email OTP | لا يناسب الهاتف كعامل أساسي | نعم | لا يفي بمتطلب التحقق برقم الهاتف؛ يبقى خيار استرداد فقط. |

الأسعار غير مذكورة لأنها تتغير ولا يجوز افتراضها. المطلوب عروض سعر رسمية لكل مزود مع سعر الرسالة الناجحة، والحد الأدنى الشهري، وتكلفة الاختبار.

## المعايير المرجحة
1. نسبة التسليم الفعلية لأرقام يمنية من مشغلين مختلفين، لا مجرد «مدعوم».
2. زمن الوصول الوسيط وp95.
3. وضوح فشل التسليم وإمكانية إعادة المحاولة دون ازدواج.
4. دعم sender ID محلي إن تطلب الأمر.
5. حدود المعدل وسياسة مكافحة الاحتيال.
6. عقد البيانات والاحتفاظ وسجل التدقيق.
7. جودة Sandbox وتوثيق API.
8. قابلية استبدال المزود وعدم ربط قاعدة البيانات بمزود واحد.

## التوصية
- عدم شراء أي مزود الآن.
- تنفيذ اختبار قبول صغير على رقمين يمنيين من مشغلين مختلفين لكل مرشح، بموافقة المستخدم.
- التفضيل المبدئي: مجمّع محلي كقناة أساسية + Twilio كقناة احتياطية، مع تجنب الاعتماد على WhatsApp كقناة وحيدة.
- إبقاء `OtpDeliveryAdapter` الحالي وعدم إدخال مفاتيح مزود في الكود أو المستودع.

## الحالة
- منفَّذ: adapter قابل للاستبدال وtest adapter محلي فقط.
- غير منفَّذ: مزود حقيقي، تعاقد، إرسال إنتاجي، قياس تسليم يمني.
- مؤجَّل: التفاوض التجاري والشراء حتى موافقة صريحة.
